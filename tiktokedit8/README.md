# TikTok edit 8

Published red car review at https://venturasolutions.co.uk/tiktokedit8/.

Eight 2160 × 3840 60 fps videos, 57 ordered cut thumbnails, whole video and clip likes/dislikes, independent comments, downloads, round selection and JSON/text feedback export.

The original HEVC exports and same resolution H.264/AAC playback copies are immutable assets on the `tiktokedit8-round-01` GitHub release. Original files exceed GitHub's normal repository file limit. All media URLs are in the round manifest. No localhost links are used.

Feedback saves immediately in this browser's localStorage and automatically to the TextDB store in `online-config.js`. Each browser has a separate draft. Send answers also saves a named snapshot. Results and all feedback download are at `results.html`. This is an unlisted public review page; the shared feedback store is unauthenticated. It uses read/merge/write and cannot guarantee simultaneous reviewer writes. Failed reads never trigger an empty overwrite. Browser drafts and manual downloads remain available if online saving fails.

Local originals and feedback remain in the 13 October red car task under `outputs/video-review`. For the next edit, use that task's `pull-online-feedback.py` to download the hosted reports locally. Out times and out frames are exclusive. Add revised exports under a new round ID with a new manifest and preserve round 1 and its release assets.

Only this route was added; existing Ventura pages are not part of this change.
